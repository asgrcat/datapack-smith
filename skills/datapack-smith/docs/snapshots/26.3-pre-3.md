# Java Edition 26.3 Pre-Release 3

launcher IDは`26.3-pre-3`、data pack formatは121.0です。Pre-Release 2の仕様を継承し、context依存float number providerの剰余と累乗の評価規則をinteger variantへ揃えます。

## metadata

```json
{
  "pack": {
    "description": "26.3-pre-3 data pack",
    "min_format": [121, 0],
    "max_format": [121, 0]
  }
}
```

## コマンド

- コマンド構文の追加・変更・削除は公式リリースノートに記載なし
- `/compute`と`data modify ... compute`のinteger／float branchを継承
- float providerを評価する式には、下記の`mod`／`pow`変更が適用される

## JSON/NBT/registry

- data pack formatを120.0から121.0へ更新
- context依存float `minecraft:mod`をfloor modulusからinteger variantと同じ通常の剰余へ変更（MC-311651）
- context依存float `minecraft:pow`で`0^0`を評価するとerrorで計算を中止するよう変更（MC-311650）
- field、負数の計算例、評価失敗の扱いは[number provider reference](../reference/number-providers.md#pre-release-3の演算変更)を参照
- villagerとの取引中にreputationが0になる場合やrestockされる場合に、支払いなしで取引できる不具合を修正（MC-311678、MC-311679）。trade JSONのschema変更としては扱わない

## 互換性

120.0向けpackはmetadataを121.0へ更新し、float `mod`で負数を含む式と、float `pow`で底・指数がともに0になり得る式を点検します。provider resourceだけでなく、loot、predicate、item component、villager tradeなどにinlineで埋め込んだ式も対象です。

それ以外の仕様はPre-Release 2を継承します。開発バージョン間の互換性は保証されないため、対象JARで再検証します。

## JSONパラメータ差分

- **item**: 26.3-pre-2を継承。float providerを受けるcomponent fieldでは演算変更を適用
- **dimension/worldgen**: 26.3-pre-2を継承。context非依存worldgen providerへ今回の変更を一律に適用しない
- **enchantment**: 26.3-pre-2を継承。context依存float providerを使う箇所では演算変更を適用
- **variant**: 26.3-pre-2を継承。固有のvariant registry変更は公式記事に記載なし
- **predicate**: context依存float providerを使う条件では演算変更を適用
- **advancement**: condition内でcontext依存float providerを使う場合は演算変更を適用
- **loot_table**: float providerを受けるfieldでは演算変更を適用
- **recipe**: 26.3-pre-2を継承。固有のrecipe schema変更は公式記事に記載なし
- **item_modifier**: float providerを受けるfieldでは演算変更を適用
