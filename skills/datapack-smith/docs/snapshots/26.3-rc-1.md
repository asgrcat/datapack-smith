# Java Edition 26.3 Release Candidate 1

launcher IDは`26.3-rc-1`、data pack formatは121.0です。Pre-Release 3の仕様を継承する修正中心の開発バージョンで、正式リリース`26.3`とは分離します。

## metadata

```json
{
  "pack": {
    "description": "26.3-rc-1 data pack",
    "min_format": [121, 0],
    "max_format": [121, 0]
  }
}
```

## コマンド

- `/compute`と`data modify ... compute`のinteger／float branchを継承
- float `mod`の通常の剰余と、float `pow`の`0^0`評価中止を継承

## JSON/NBT/registry

- data pack formatはPre-Release 3と同じ121.0
- `weapon.disable_blocking_for_seconds`を設定したitemで`blocks_attacks`を持つitemの防御を無効化できない不具合を修正（MC-311607）。axeでshieldを無効化できない不具合も修正（MC-311705）
- loot predicate `match_block`が常にblock entityを要求してしまう不具合を修正（MC-311725）
- これらは挙動修正として扱い、component／predicate fieldの追加・改名とは解釈しない。利用時の確認項目は[component／predicate reference](../reference/components-and-predicates.md#263-release-candidate-1の挙動修正)を参照

## 互換性

Pre-Release 3向けの121.0固定metadataを継続して使えます。ただしformatが同じでも防御無効化や`match_block`の判定結果が変わるため、対象launcher IDのJARで再検証します。Release Candidateを正式リリースのプロファイルへ丸めません。

## JSONパラメータ差分

- **item**: `weapon`と`blocks_attacks`の防御無効化に関する挙動を修正
- **dimension/worldgen**: 26.3-pre-3を継承
- **enchantment**: 26.3-pre-3を継承
- **variant**: 26.3-pre-3を継承
- **predicate**: `match_block`の過剰なblock entity要求を修正
- **advancement**: 26.3-pre-3を継承。`match_block`を利用するconditionでは修正後の判定を確認
- **loot_table**: `match_block`を利用するconditionでは修正後の判定を確認
- **recipe**: 26.3-pre-3を継承
- **item_modifier**: `match_block`を利用するconditionでは修正後の判定を確認

## AI 生成規則

- launcher IDを`26.3-rc-1`、data pack formatを121.0へ固定し、`26.3`や`26.3-rc1`へ丸めない
- Release Candidateも`channel: snapshot`として扱い、project設定の`experimental_features: true`を要求する
- context依存integer／float providerのregistryとconsumer fieldを一致させる
- float `mod`へfloor modulusの結果を期待せず、float `pow`の`0^0`を入力制約または分岐で避ける
- structure tagには`#minecraft:on_abandoned_camp_windswept_forest`を使い、`minecraft:context_key_set`の独自element fileを出力しない
- `match_block`の不具合回避だけを目的に、block entityを持つblockへ対象を限定しない
- 対象JARでreport、vanilla data、reload、防御無効化とpredicateの判定を再検証する

## 検証

公式server JAR（SHA-1 `7ae096efda2563d58a0c01575256f3db7669d386`）の`version.json`で121.0とJava 25を確認しました。生成したreport／vanilla dataは、ハーネスの来歴metadataを除きPre-Release 3と差分がありません。

両JARのbytecodeを比較し、`MatchBlock.getReferencedContextParams`が`BlockPredicate.willMatchBlockEntity`に応じて`BLOCK_ENTITY`を要求する変更と、`LivingEntity`／`Player`の防御処理変更を確認しました。server reload／ゲーム内テストは未実施です。

公式記事は取得できず、Feedback APIはRCの見出しに古いsnapshotの本文を返したため採用していません。修正項目の照合にはリリース告知の転載を補助的に使い、仕様の根拠は公式JARとmanifestとします。
