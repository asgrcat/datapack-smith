# Java Edition 26.3 Pre-Release 2

launcher IDは`26.3-pre-2`、data pack formatは120.0です。Pre-Release 1の仕様を継承し、Abandoned CampのWindswept系structure tagをWindswept Forestと明示するIDへ改名します。

## metadata

```json
{
  "pack": {
    "description": "26.3-pre-2 data pack",
    "min_format": [120, 0],
    "max_format": [120, 0]
  }
}
```

## コマンド

- コマンド構文の追加・変更・削除は公式リリースノートに記載なし
- `/compute`と`data modify ... compute`は、Pre-Release 1で導入されたinteger／float branchとcontext providerの規則を継承
- MC-311594の修正により、一部number providerを`/compute`で使った際の予期しないerrorを修正

## JSON/NBT/registry

- data pack formatを119.0から120.0へ更新
- structure tag `#minecraft:on_abandoned_camp_windswept`を`#minecraft:on_abandoned_camp_windswept_forest`へ改名
- 旧tag IDは削除されるため、Abandoned CampのWindswept Forest向け参照をすべて新IDへ移行
- 公式JARのreportへtag対応の`minecraft:context_key_set` registryを追加。data packからelementは追加できず、`generic`、`command_compute_*`、advancement、block／entity interaction等の31 entryを公開
- generic loot contextの不足parameterと、未提供parameterを参照した一部`LootContextUser`のcrashを修正。必要parameterが呼出元にないJSONを有効とみなす変更ではない
- vanillaのcold／warm kelp placed featureへ、1block下の上面が頑丈であることと`#minecraft:cannot_support_kelp`除外を組み合わせた配置条件を追加
- Pre-Release 1のcontext依存integer／float number provider、cooking recipe、block state provider、loot、predicate、item component、villager tradeの変更を継承

## 互換性

119.0向けpackはmetadataを120.0へ更新したうえで、`#minecraft:on_abandoned_camp_windswept`への参照を`#minecraft:on_abandoned_camp_windswept_forest`へ置換します。旧IDを互換用に残してもvanillaの新tagへ自動転送されないため、structure tagを参照するpredicate、loot、worldgen、functionを検索して移行します。

それ以外のデータパック仕様はPre-Release 1を継承します。ただし開発バージョン間の互換性は保証されないため、120.0へ固定したmetadataとPre-Release 2の公式server JARで再検証します。

## JSONパラメータ差分

- **item**: 26.3-pre-1を継承。固有のitem component／item tag変更なし
- **dimension/worldgen**: Abandoned CampのWindswept系structure tagを`on_abandoned_camp_windswept_forest`へ改名し、vanilla kelpの配置条件を修正
- **enchantment**: 26.3-pre-1を継承。固有のenchantment変更なし
- **variant**: 26.3-pre-1を継承。固有のvariant registry変更なし
- **predicate**: structure tagを参照する条件では新IDへ移行。`context_key_set`のreport公開とloot context修正を適用
- **advancement**: conditionから旧structure tagを参照している場合は新IDへ移行
- **loot_table**: conditionから旧structure tagを参照している場合は新IDへ移行。vanilla Abandoned Camp loot tableのExplorer Map destinationも新tagへ変更
- **recipe**: 26.3-pre-1を継承。固有のrecipe変更なし
- **item_modifier**: conditionから旧structure tagを参照している場合は新IDへ移行

## AI 生成規則

- launcher IDを`26.3-pre-2`、data pack formatを120.0へ固定し、`26.3-pre-1`や`26.3-pre2`へ丸めない
- `#minecraft:on_abandoned_camp_windswept`を出力せず、`#minecraft:on_abandoned_camp_windswept_forest`を使う
- `minecraft:context_key_set`の独自element fileを出力せず、組み込みentryまたはtagだけを参照する
- Pre-Release 1から継承するinteger／float number providerのregistryとconsumer fieldを維持する
- Pre-Release 2の公式JARでcommand report、datapack registry、vanilla data、reload、structure tag参照を再検証する
