# Java Edition 26.4 Snapshot 2

Snapshot 1を継承する開発バージョンです。launcher IDは`26.4-snapshot-2`、data pack formatは122.1です。正式26.3の仕様にSnapshot 1、2の差分を適用します。

## metadata

```json
{
  "pack": {
    "description": "26.4-snapshot-2 data pack",
    "min_format": [122, 1],
    "max_format": [122, 1]
  }
}
```

## コマンド

- 生成したコマンド木はSnapshot 1と一致。`/fillbiome`のblock単位化、NBT整数変換、`/test`の回転引数制限を継承
- 三角関数の角度wrapと周期性の不具合を修正（MC-311780）。公式記事は修正対象の全consumerを列挙していないため、任意のnumber providerへ同じ変更を推測で適用しない

## JSON/NBT/registry

- environment attribute `minecraft:visual/has_sky_occluder`を追加。boolean、補間なし。Overworldではtrue、Nether／Endではfalse。空をfog色で遮蔽する表示設定で、地形や光量の条件とは区別する
- worldgen block predicate `minecraft:below_heightmap`を追加。必須field `heightmap`で指定したheightmapの高さより、評価位置のYが小さい場合に成立する。等しい場合は不成立
- vanillaのキノコplaced feature 9件に`below_heightmap`と`MOTION_BLOCKING`を使うfilterを追加。沼地でのキノコ過剰生成修正（MC-312046）に関連
- registry reportでは`minecraft:rule_test`が`minecraft:rule_test_type`へ変わった。`reports/datapack.json`では引き続き`elements: false`、`tags: true`。独自elementを置くregistryの追加とは解釈しない
- sound event `minecraft:entity.zombie_nautilus.riding`を追加（JAR report）
- vanilla advancement `adventure/root`のiconを`minecraft:map`から`minecraft:buried_treasure_map`へ変更。criteria形式の変更ではない
- noise settings 3件の`debug_functions[].label`を読みやすい表示へ変更。density functionのschema変更とは区別する
- lily pad／frogspawn設置時のused統計（MC-264274）、sculk catalyst付近でarmor stand等を壊した際の経験値消費（MC-311924）、chunk生成中のクラッシュ（MC-312064）を修正

## 互換性

formatのminor更新です。Snapshot 1へ新しいattribute／predicateを出力しません。単一対象のpackは上の122.1固定metadataを使います。`max_format: 122`はmajor 122の全minorを許可するため、厳密固定とは異なります。既存のrule test registry参照やtagを使う場合も対象reportを再確認します。

F3再設計、霧・天空・雲の描画改善、resource pack format 99.0とshader変更は、データパックのJSON schema変更と区別します。

## JSONパラメータ差分

- **item**: Snapshot 1を継承。固有のcomponent schema変更は公式記事に記載なし
- **dimension/worldgen**: `visual/has_sky_occluder`、`below_heightmap`、キノコ配置filter、noise debug labelを追加・更新
- **enchantment**: Snapshot 1を継承。固有の変更は公式記事に記載なし
- **variant**: Snapshot 1を継承。固有の変更は公式記事に記載なし
- **predicate**: worldgen block predicateへ`below_heightmap`を追加。loot conditionとは別のcodec
- **advancement**: vanilla `adventure/root`のiconを変更。schemaは継承
- **loot_table**: Snapshot 1を継承。固有の変更は公式記事に記載なし
- **recipe**: Snapshot 1を継承。固有の変更は公式記事に記載なし
- **item_modifier**: Snapshot 1を継承。固有の変更は公式記事に記載なし

## AI 生成規則

- launcher IDを`26.4-snapshot-2`、formatを122.1へ固定し、未収録の正式`26.4`へ丸めない
- project設定に`experimental_features: true`を要求する
- 正式26.3のprovider型・参照形式と、Snapshot 1のworldgen移行を継承する。`default_block`を出力せず、cuboidを実寸とし、空の`fixed_placement.positions`を作らない
- `below_heightmap`は`type`を持つworldgen block predicateとして使い、`condition`を持つloot predicateへ置換しない。heightmapは対象JARの大文字enum値を使う
- `visual/has_sky_occluder`はbooleanとしてattributesへ設定し、ゲーム内の遮蔽・光量判定に流用しない
- 対象JARのreport／vanilla dataと、reload・worldgen・表示・統計の実動作を分けて検証する

## 検証

公式記事・manifestを照合し、server JARのSHA-1 `e6cac6e2fa35d5847e60dede721ec75f7a28c34d`を検証。`version.json`でformat 122.1、Java 25、`stable: false`を確認しました。report／vanilla data生成は成功し、Snapshot 1とのコマンド木の一致、上記registryとJSON差分を確認しています。
