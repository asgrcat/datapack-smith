# Java Edition 26.3 Snapshot 10

data pack format 118.0。number providerをコマンドから評価できるようにし、block transformerを独立registryへ移します。loot functionとnoise settings／density function／material ruleにも破壊的変更があります。

## metadata

```json
{
  "pack": {
    "description": "26.3-snapshot-10 data pack",
    "min_format": [118, 0],
    "max_format": [118, 0]
  }
}
```

## コマンド

- `/compute <target> <provider> [<scale>|integer]`を追加
  - `target`は`default`、`block <pos>`、`entity <entity selector>`
  - `provider`は`minecraft:number_provider` registry IDまたはinline値
  - 全targetで`origin`を現在のコマンド位置、`this` entityを`@s`から設定する
  - `block`は指定位置の`block_state`と`block_entity`、`entity`はselector結果の`target_entity`も設定する
  - `scale`は既定1.0で、最終結果へ乗算して負の無限大方向へ丸める
  - `integer`は中間段階でも整数化するため、scale 1.0のfloat modeと同値とは限らない
- `/data modify ... append|insert|merge|prepend|set compute <target> <provider> [integer]`を追加
  - number providerの評価結果をintegerまたはfloat tagとして書き込む
  - target、provider、integer modeの文脈は`/compute`と同じ
- `/swing`のanimation typeへ`none`を再追加
- `/locate`のstructure探索性能を改善。command treeの引数構造は対象JARで再確認する

## JSON/NBT/registry

- `minecraft:consumable`の`teleport_randomly` consume effectへ任意boolean `directional_particles`を追加。既定値は`true`
- `minecraft:block_transformer` item componentを変更
  - inline objectを廃止し、常に`minecraft:block_transformer` registryのIDを参照する
  - 新registry entryは変換rule objectのlist
  - 各ruleは必須`block_state_provider`と、任意の`sound`、`particle`、`disallowed_faces`、`loot`、`drop_strategy`、`update_from_neighbors`、`transform_type`、`consume_on_use`、`item_damage_per_use`を持つ
  - `particle`は`none`／`scrape`／`wax_on`／`wax_off`、`drop_strategy`は`from_middle`／`clicked_face`、`transform_type`は`single_block`／`copper_chest`
  - 任意fieldの既定値は順に無音、`none`、空list、lootなし、`from_middle`、`true`、`single_block`、`true`、`0`
  - vanilla entryは`minecraft:shovel`、`minecraft:axe`、`minecraft:hoe`
- `minecraft:attack_animation`／`minecraft:interact_animation`
  - `none` swing animation typeを再追加
  - `duration`を非負integerへ変更
- loot table typeを追加
  - `minecraft:command_compute_default`: `origin`、任意の`this` entity
  - `minecraft:command_compute_position`: default文脈に`block_entity`と`block_state`を追加
  - `minecraft:command_compute_entity`: default文脈に`target_entity`を追加
- loot function `minecraft:set_loot_table`を変更
  - 未使用の`type`を削除
  - `tag`を`loot_table_id`へrename
- noise settingsを変更
  - `preliminary_surface_level`を`chunk_surface_level`へrenameし、chunk全体で暗黙にinterpolateしない
  - `ore_veins_enabled`を削除し、`minecraft:ore_vein` material ruleへ置換
  - `noise.size_horizontal`／`noise.size_vertical`を削除し、`minecraft:interpolated`の`cell_size_xz`／`cell_size_y`へ移動
  - 任意の`debug_functions`を追加。各要素はstring `label`とdensity function `function`を持つ
- material rule `minecraft:ore_vein`を追加
  - `ore_block`、`raw_ore_block`、`filler_block`、0〜1の`raw_ore_chance`、density functionの`density`／`richness`／`filler_gap`を受ける
- density functionを変更
  - `minecraft:noise`へ任意の`shift_x`／`shift_y`／`shift_z`を追加。省略時は0
  - `minecraft:shifted_noise`を削除し、`minecraft:noise`へ統合
  - `minecraft:interpolated`へ正integer `cell_size_xz`／`cell_size_y`を追加
  - `minecraft:cache_once`を同一書式の`minecraft:cache`へrename
  - `minecraft:cache_2d`、`minecraft:cache_all_in_cell`、`minecraft:flat_cache`を削除
- block tag `#minecraft:nether_portal_frame`、`#minecraft:conduit_effect_block`を追加
- structure tagをrename
  - `#minecraft:on_woodland_explorer_maps` → `#minecraft:on_woodland_mansion_maps`
  - `#minecraft:on_ocean_explorer_maps` → `#minecraft:on_ocean_monument_maps`
  - `#minecraft:on_jungle_explorer_maps` → `#minecraft:on_jungle_pyramid_maps`
  - `#minecraft:on_swamp_explorer_maps` → `#minecraft:on_swamp_hut_maps`
  - `#minecraft:on_trial_explorer_map` → `#minecraft:on_buried_trial_chambers_maps`
- fluid tag `#minecraft:axolotl_tries_to_find`、`#minecraft:dolphin_tries_to_find`、`#minecraft:frog_tries_to_find_land_near`、`#minecraft:entity_floatable`を追加
- structure／fluid tagは公式記事の説明的表記でなく、Snapshot 10の公式JARが生成したresource pathを上記IDの正本とする

## 互換性

117.0のinline `minecraft:block_transformer` componentは118.0で無効です。objectを`data/<namespace>/block_transformer/<path>.json`のregistry entryへ分離し、componentからnamespaced IDで参照します。

`minecraft:set_loot_table`の`type`を削除し、`tag`を`loot_table_id`へrenameします。旧fieldを互換用に併記せず、対象JARでitem modifier全体をreload検証します。

worldgenではfield名だけを機械置換しません。`chunk_surface_level`の補間挙動、ore veinのmaterial rule、interpolation cell size、shift統合、cache削除をまとめて移行し、新規worldと未生成chunkで生成結果と性能を比較します。`flat_cache`の旧Y固定が必要な式は`minecraft:slice`等で意図を明示します。

Explorer Map用structure tagは旧IDと新IDを同時に出力せず、参照側とtag定義を一括renameします。block／fluid tagをoverrideする場合はvanilla entryを保つため`replace: false`を明示します。

## JSONパラメータ差分

- **item**: `consumable.teleport_randomly.directional_particles`を追加。`block_transformer` componentをregistry ID参照専用へ変更。animation componentの`none`を再追加し、`duration`を非負integer化
- **dimension/worldgen**: block transformer registry、noise settings／material rule／density functionの破壊的変更、block／structure／fluid tagの追加・renameを適用
- **enchantment**: 26.3-snapshot-9を継承。固有のenchantment effect schema追加・変更・削除なし
- **variant**: 26.3-snapshot-9を継承。固有のvariant registry追加・変更・削除なし
- **predicate**: 26.3-snapshot-9を継承。固有のcondition追加・変更・削除なし
- **advancement**: 26.3-snapshot-9のroot背景制約を継承。固有のtrigger／field追加・変更・削除なし
- **loot_table**: command compute用parameter set 3種を追加。table／pool／entry schema固有の変更なし
- **recipe**: 26.3-snapshot-9を継承。固有のserializer schema追加・変更・削除なし
- **item_modifier**: `set_loot_table.type`を削除し、`tag`を`loot_table_id`へrename。command compute用loot contextでnumber providerを評価可能

## AI 生成規則

- data pack formatを118.0へ固定し、`/compute`と`data modify ... compute`ではtargetが公開するloot context parameterだけを参照する
- `integer` modeとfloat modeを同値扱いせず、負数、scale、中間小数を含む式を再検証する
- `minecraft:block_transformer` componentへinline objectを出力せず、registry entryへ分離してID参照する
- animation componentの`duration`へ負数または小数を出力しない
- `set_loot_table`へ旧`type`／`tag` fieldを出力しない
- 117.0以前のnoise settings／density function／structure tag IDを118.0へ残さない
- worldgen移行は既存worldで検証せず、Snapshot 10の新規実験worldと未生成chunkを使用する
- Snapshot 10の公式JARでcommand report、datapack registry、vanilla data、reload、number provider文脈、worldgenを再検証する
