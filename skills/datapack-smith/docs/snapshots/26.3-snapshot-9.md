# Java Edition 26.3 Snapshot 9

data pack format 117.0。advancementの背景検証を厳格化し、number providerを再編・拡張します。teleportation、brewing、potion挙動を制御するtagも追加されます。

## metadata

```json
{
  "pack": {
    "description": "26.3-snapshot-9 data pack",
    "min_format": [117, 0],
    "max_format": [117, 0]
  }
}
```

## コマンド

26.3-snapshot-8のcommand差分を継承します。Snapshot 8とSnapshot 9の公式server JARが生成した`commands.json`は同一で、固有のcommand tree追加・変更・削除はありません。

## JSON/NBT/registry

- advancementの`display.background`を厳格化
  - `display`を持ち`parent`を持たない可視root advancementでは`background`が必須
  - `background`を指定できるのはroot advancementだけ
- slot source `minecraft:group`のinline定義は、slot sourceのトップレベル定義ファイルでだけ使用可能
- loot function `minecraft:sequence`のinline定義は、item modifierのトップレベル定義ファイルでだけ使用可能
- number provider `minecraft:sum`を変更
  - `summands`を`operands`へrename
  - `operands`はnumber providerのinline値、単一namespaced ID、IDのlist、inline値のlist、`#`付き`minecraft:number_provider` tag IDを受ける
  - 1個以上のoperandが必須
  - integer modeでは中間加算にもinteger modeを適用
- number provider `minecraft:product`、`minecraft:minimum`、`minecraft:maximum`、`minecraft:average`を追加
  - いずれも`sum`と同じ形式の空でない`operands`を受ける
  - 順に積、最小値、最大値、平均値を返す
- block tagを追加
  - `#minecraft:uncarvable`
  - `#minecraft:dangerous_for_teleportation`
  - `#minecraft:cat_does_not_teleport_to`
  - `#minecraft:enderman_does_not_teleport_to`
  - `#minecraft:shulker_does_not_teleport_to`
  - `#minecraft:consumable_does_not_teleport_to`（vanillaでは空）
- item tag `#minecraft:brewing_potion_inputs`を追加
- potion tag `#minecraft:douses_fire`、`#minecraft:hurts_water_sensitive_entities`、`#minecraft:extinguishes_entities`、`#minecraft:rehydrates_axolotls`を追加
- 空のdamage type tag `#minecraft:bypasses_cooldown`を追加（公式JAR生成物で確認）
- top-levelのitem modifier／slot source定義ファイル全体をnamespaced ID文字列の参照にできない不具合を修正
- vanillaのcooking用number providerを再構成
  - `fast_burn_time_multiplier`、`fast_speed_multiplier`、`normal_burn_time_multiplier`、`normal_speed_multiplier`を追加
  - cooking timeを定数の直接分岐から、基準値とburn-time multiplierの`minecraft:product`へ移行
- vanilla villager tradeの`minecraft:sum`を`operands`へ移行

## 互換性

116.0の`minecraft:sum.summands`は117.0で無効です。`operands`へrenameし、空listを出力しません。新しい4種のnumber providerを116.0以前へ持ち込まず、integer modeの`sum`は各中間結果がintegerとして扱われる前提で境界値とoverflowを再検証します。

可視root advancementへ`background`がない場合や、子advancementへ`background`を残した場合はvalidationに失敗します。advancement tree全体を走査し、`parent`の有無と`display.background`を同時に移行します。

`group`と`sequence`のinline objectをnested位置へ埋め込まず、再利用する場合はそれぞれslot sourceまたはitem modifierのトップレベルresourceへ分離してnamespaced IDで参照します。

新しいteleportation／potion tagをoverrideする場合はvanilla entryを消さないよう`replace: false`を明示し、Enderman、Shulker、Cat、random teleporting food、splash potionの挙動を機能testします。

## JSONパラメータ差分

- **item**: `#minecraft:brewing_potion_inputs` item tagとpotion tag 4種を追加。item component schema固有の変更なし
- **dimension/worldgen**: carver／teleportation制御用block tag 6種を追加。空の`#minecraft:bypasses_cooldown` damage type tagも追加。worldgen codec固有の変更なし
- **enchantment**: number providerを使うeffect fieldでは`sum`の`operands` rename、追加provider 4種、integer modeの中間演算を適用
- **variant**: 26.3-snapshot-8を継承。固有の追加・変更・削除なし
- **predicate**: number providerを使うcondition fieldでは`sum`の`operands` renameと追加provider 4種を適用。condition集合固有の変更なし
- **advancement**: 可視rootの`display.background`を必須化し、子advancementの`background`を禁止。number provider差分も適用
- **loot_table**: inline `minecraft:sequence`をitem modifierのトップレベル定義に限定。number provider差分を適用
- **recipe**: `#minecraft:brewing_potion_inputs`を追加。brewingを含むserializer schema固有の変更なし
- **item_modifier**: top-level file全体のID参照を修正。inline `minecraft:sequence`をトップレベル定義に限定し、number provider差分を適用

## AI 生成規則

- data pack formatを117.0へ固定し、`minecraft:sum`へ`summands`や空の`operands`を出力しない
- `product`／`minimum`／`maximum`／`average`の`operands`を1個以上にする
- 可視root advancementには`display.background`を必ず出力し、`parent`を持つadvancementには出力しない
- nested slot sourceへinline `minecraft:group`を、nested loot functionへinline `minecraft:sequence`を出力しない
- 新しいtagを追加・上書きする場合は対象registryと`replace`の意図を明示する
- vanillaで空の`#minecraft:consumable_does_not_teleport_to`へ推測したblockを追加しない
- Snapshot 9の公式JARでcommand report、registry、vanilla data、reload、advancement validation、number providerの境界値を再検証する
