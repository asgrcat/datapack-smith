# Java Edition 26.4 Snapshot 4

Snapshot 3を継承する開発バージョンです。launcher IDは`26.4-snapshot-4`、data pack formatは124.0です。Brittle Iceとジュークボックスのplaylist、fluid state再編、音fieldの省略対応、crevasse featureを追加・変更しています。

## metadata

```json
{
  "pack": {
    "description": "26.4-snapshot-4 data pack",
    "min_format": [124, 0],
    "max_format": [124, 0]
  }
}
```

## コマンド

- 生成したコマンド木はSnapshot 3と一致。構文が同じでも、引数に使うregistry IDの削除・追加を反映する
- block／item ID `minecraft:brittle_ice`を追加。block stateの`age`は`0`、`1`、`2`、`3`
- sound event `minecraft:intentionally_empty`を削除。氷系21件と`minecraft:entity.drowned.converted_to_zombie`、JARで確認した`minecraft:entity.chicken_picky.step`を追加。新しいsound eventは23件

## JSON/NBT/registry

- fluid ID `minecraft:flowing_water`／`minecraft:flowing_lava`を削除。`minecraft:water`／`minecraft:lava`のfluid stateは`level`（整数1〜8）と`source`（boolean）で区別し、旧`falling` propertyを使わない。block stateのwater／lava `level`とは別の型・値域
- worldgen block predicate `minecraft:matching_fluids`へ省略可能な`state`を追加。省略時はstate条件なし。水源を選ぶ既存判定は`source: "true"`を加え、流水まで一致させない。[fluidとpredicateの移行](../json-parameters/predicates.md#264-snapshot-4のfluidとmatching_fluids)
- sound eventの無音用ID削除に合わせ、Sulfur Cube archetypeとchicken／cow／cat／pig／wolf sound variantの音fieldを省略可能へ変更。[field一覧](../reference/sounds-and-particles.md#264-snapshot-4のsound移行)
- enchantment entity effect `minecraft:explode`の`small_particle`、`large_particle`、`sound`を省略可能へ変更。省略時は該当する演出を指定しない。[enchantment差分](../json-parameters/enchantments-variants.md#264-snapshot-4のenchantmentとsound-variant)
- block sound set `minecraft:amethyst`を`minecraft:amethyst_block`へ改名。`blue_ice`、`brittle_ice`、`frosted_ice`、`packed_ice`を追加
- feature type `minecraft:crevasse`を追加。surfaceに沿う裂け目の幅・長さ・連結面積・曲率・深さ・block provider・predicateを設定する。vanilla resourceは`worldgen/feature/ice_crevasse.json`と`worldgen/placed_feature/ice_crevasse.json`。[全必須fieldと値域](../reference/worldgen.md#264-snapshot-4の開発差分)
- Brittle Iceはice cavesのcrevasseに生成。踏むとひびが入り破壊され、Silk Touchで取得できる。水がblue iceへ流れると、その水平隣接water blockがBrittle Iceへ変わる
- ジュークボックス直上の単体chest／trapped chest／copper chest系からdiscをslot順に循環再生。空slotとdisc以外を飛ばし、再生終了時に交換する。discがなければ現在のdiscを再生し、取り出すと次のdiscへ進む
- block tag `jukebox_containers`、`face_occluding_ice_blocks`、JARで確認した`ice_crevasse_replaceables`を追加。item tag `jukebox_containers`も追加
- entity type tag `does_not_break_brittle_ice`を追加。vanillaはFrostbiteだけを含む。`freeze_immune_entity_types`へzombie／drowned／huskを追加。Freezingでdamageを受けず、粉雪内のDrownedはZombieを経てFrostbiteへ変わる
- damage type tag `no_hurt_sound`を追加。vanillaの値は空。menu registryに`minecraft:jukebox`を追加
- biome tag `is_cave`へice cavesを追加。vanilla biomeのgravel生成、End biomeのsky occluder、Frost Walkerや水源を要求するfeatureのfluid条件を更新
- Frosted Iceのstate変更でvibration eventを発生。world borderを越えるEnderman／chorus fruit移動（MC-311312）、一撃で壊したarmor standのsculk shrieker反応（MC-312256）、saddle slotのcustom equipping sound（MC-280455）等を修正

## 互換性

124.0固定metadataへ更新し、削除fluid／sound event ID、旧fluid `falling`、水源判定、block sound set改名を検索して移行します。音を省略できるfieldだけで無音用IDを削除し、引き続き必須のfieldまで省略しません。新しいschemaとIDをSnapshot 3以前や正式26.3へ遡及しません。

resource pack format 100.1、textureと内部面の描画、networkの切断処理は、データパックのJSON仕様と区別します。

## JSONパラメータ差分

- **item**: Brittle Iceと`jukebox_containers` tagを追加。既存component schemaは継承
- **dimension/worldgen**: crevasse feature、ice crevasse resource・tag、fluid state再編とwater source条件、biome配置を追加・変更
- **enchantment**: `minecraft:explode`の3つの演出fieldを省略可能へ変更。vanilla Frost Walkerの`matching_fluids`に`state.source`を追加
- **variant**: chicken／cow／cat／pig／wolf sound variantの音fieldを省略可能へ変更。Sulfur Cube archetypeの`hit_sound`／`push_sound`も省略可能
- **predicate**: worldgen `matching_fluids.state`を追加。fluid IDとpropertyを移行。独立loot predicateとworldgen predicateを混同しない
- **advancement**: Snapshot 3を継承。生成したvanilla advancement JSONに差分なし
- **loot_table**: `blocks/brittle_ice`を追加。Silk Touch条件を含み、schemaは継承
- **recipe**: Snapshot 3を継承。生成したvanilla recipe JSONに差分なし
- **item_modifier**: Snapshot 3を継承。固有のschema変更は公式記事に記載なし

## AI 生成規則

- launcher IDを`26.4-snapshot-4`、formatを124.0へ固定し、未収録の正式`26.4`へ丸めない
- project設定へ`experimental_features: true`を要求する
- 正式26.3のprovider型・参照形式とSnapshot 1〜3のworldgen移行を継承する。`default_block`と`minecraft:item_snowball`を出力しない。large featureのtypeは`minecraft:large_speleothem`
- `flowing_water`／`flowing_lava`と旧fluid `falling`を出力しない。水源はfluid `source`条件で明示し、block stateの`level`とfluid stateの`level`を混同しない
- `minecraft:intentionally_empty`を出力せず、対象codecで任意になった音fieldを省略する。block sound setの旧`minecraft:amethyst`参照を移行する
- `matching_fluids.state`はworldgen predicateとして使い、対象propertyの名前・型・値域を守る
- crevasseは`type`と14個の必須fieldを揃え、`carve_depth`／`fill_depth`には正の値だけを生成するinteger providerを使う
- 新しいmob・fluid・playlist・氷blockの挙動、worldgen、reloadを対象JARで検証する

report／vanilla data生成は成功。Snapshot 3比で15ファイル追加、1ファイル削除、97ファイル変更（data generatorの`.cache`を除外し、ハーネス来歴metadataを含む）、コマンド木は一致です。registryのID差分、Brittle Iceのstate、fluid tag、音の改名、crevasseとFrost Walkerの生成JSONを照合しました。`matching_fluids`、fluid state、crevasse、任意化された音fieldとexplode effectのcodecもJARで確認しました。
