# Java Edition 26.4 Pre-Release 2

[Pre-Release 1](26.4-pre-1.md)を継承する開発バージョンです。launcher IDは`26.4-pre-2`、data pack formatは128.2です。壁の形状判定用block tagを追加し、jigsawの候補配置やblock state providerの動作を修正します。[^mojang-pre-2][^manifest-v2]

## metadata

```json
{
  "pack": {
    "description": "26.4-pre-2 data pack",
    "min_format": [128, 2],
    "max_format": [128, 2]
  }
}
```

## コマンド

- 生物でないentityを対象にした失敗時に、`/effect`が対象を0件と報告する不具合を修正（MC-313537）。生物だけに適用する効果の対象を広げる変更として扱わない
- 生成`commands.json`はPre-Release 1と一致。起動中のserver console入力拒否、3D絶対整数座標の中央補正、2D local座標、効果tag、文字列引数型、slot sourceを継承する[^mojang-pre-2][^server-pre-2]

## JSON/NBT/registry

- `#minecraft:wall_side_shape_override`はblock tag。vanillaの値は`minecraft:honey_block`のみ。壁の直上にある対象blockの基本形状の下面を、通常の衝突形状の下面に代えて壁の形状判定へ使う。直上block自体の衝突形状は維持する。[配置と追記例](../json-formats.md#264-pre-release-2の壁形状tag)
- `block_transformer` componentから`random_block` providerを使用すると候補を意図せず巡回する問題を修正。現行のprovider type IDは`minecraft:random_block`（MC-311450）
- `randomized_int`は対象integer propertyがproviderの値域をすべて受け付けるか確認する。動的に解決したpropertyで範囲外を検出すると元のblock stateを返し、ログに記録する（MC-313484）。生成側で有効値へ絞る
- jigsawの配置候補が`corner_constraint`で棄却されたとき、配置空間を消費せず後続候補へ進む（MC-313329）。制約のJSON fieldや値域は継承する
- 生成`block_sound_set/straw_bed.json`の`break_sound`を`{"sound_id":"minecraft:block.straw_bed.break_leave"}`に変更。Cold Sulfur Cubeの`sound_settings.push_sound`は`minecraft:entity.sulfur_cube.fast_sliding.push`に修正
- Dispenserが着火済みのSulfur CubeからTNTを取り外す問題を修正（MC-311681）。Pig／Striderのboostがworld再読み込み後に復活する問題も修正（MC-313300）
- `loot_context_requirements.json`と`registries.json`はPre-Release 1と一致。同梱の構造NBT 1,511件は`DataVersion`だけが5131から5132に更新された[^mojang-pre-2][^server-pre-2]

## 互換性

`26.4-pre-2`を指定し、単数形folderと128.2のmetadataを使います。開発バージョンのproject設定には`experimental_features: true`が必要です。`tooltip_display.split_lines`と`upscale`のX→Z→Yの補間順を継承します。壁形状tagを使うpack、jigsawの配置候補、動的なblock state providerを移行時に確認します。

resource pack formatは104.0、world versionは5132、protocol versionは1073742174です。[^server-pre-2]

## JSONパラメータ差分

- **item**: `tooltip_display.split_lines`とdispense behaviorの書式を継承。block transformerの乱数選択とDispenserの着火済みTNT処理を修正
- **dimension/worldgen**: 壁形状tagを追加。`corner_constraint`で棄却した候補が空間を確保する問題と`randomized_int`の範囲外処理を修正。構造NBTの`DataVersion`は5132
- **enchantment**: Pre-Release 1のeffect contextとvanilla JSONを継承
- **variant**: Cold Sulfur Cubeの`push_sound`を専用の押し出し音に修正。既存fieldを使用する
- **predicate**: Pre-Release 1のcontext集合とvanilla JSONを継承
- **advancement**: Pre-Release 1の形式とvanilla JSONを継承
- **loot_table**: Pre-Release 1の`group`／`sequence`修正を継承。vanilla JSONに差分なし
- **recipe**: Pre-Release 1の形式とvanilla JSONを継承。炉を破壊したときにcooking recipe以外の保存IDを処理する不具合を修正
- **item_modifier**: Pre-Release 1の書式とloot contextを継承

## AI 生成規則

- launcher IDを`26.4-pre-2`、formatを128.2に固定し、project設定へ`experimental_features: true`を要求する
- 壁形状tagは`data/minecraft/tags/block/wall_side_shape_override.json`へ既存block IDを指定する。直上blockの基本形状が必要なときに使い、壁を対象blockとして登録しない
- `corner_constraint`は適切なpool elementへ置き、値域を守る。棄却した候補が領域を塞ぐことを前提にしない。`randomized_int`の`values`は全候補blockの有効範囲に収める
- `tooltip_display.split_lines`は任意booleanで、既定は`true`。`upscale`はX→Z→Yの順で処理する。Y軸だけのgradient anchorと`domain_warp`の制約を維持する
- console送信はserver起動完了後に行う。中央補正付き3D絶対整数座標ではX／Zだけを補正し、2D local座標では2値とyawを使用する。`^`と`~`を混在させない
- command reportの`argument.type`と文字列引数型を読み、loot等は`argument.context`と`loot_context_requirements.json`から必須値と再帰制約を確認する。`div`のoverflowによる評価失敗と、子が1つの`group`の動作を継承する
- dispense behaviorはroot listと各entryの`type`を記述し、必要なfallbackを明示する。`shoot_projectile`の必須field・音object・通常float providerを維持する
- Boat／Minecartの`entity_data.id`、particleのradius／pop_chance、slot sourceの空slot・0件、Coldの水源・浮力・gamerule判定は対象仕様に従う。旧fluid ID／状態、旧耐性tag、削除された音IDを使わない

## 検証

Mojang公式記事とmanifestを照合し、公式server JARのSHA-1 `63feac922579f0c3e0081bf1c41613de8feb5db9`、format 128.2、Java 25、`stable: false`を確認しました。Minecraft Wikiともformat、DataVersion、壁形状tagと主要な修正を照合しました。[^mojang-pre-2][^manifest-v2][^server-pre-2][^wiki-pre-2]

Pre-Release 1との生成物比較では1件追加、5件変更、削除はありません（生成cacheと来歴metadataを除外）。追加は壁形状tag、変更は実験packの`min_format` 3件と、Straw Bedのbreak sound、Cold Sulfur Cubeのpush soundです。対象JARで壁の直上blockの形状参照、jigsawの制約判定と空間確保の順序、`randomized_int`の値域判定を確認しました。[^server-pre-2]

`randomized_int`の処理を対象JARで実行し、Cave Vinesに有効な`age: 2`を適用でき、範囲外の26はログを記録して元のstateを返すことを確認しました。壁形状tagを参照する128.2の最小packは静的検査を通過しました。[^server-pre-2]

server reloadとゲーム内動作検証は未実施です。
