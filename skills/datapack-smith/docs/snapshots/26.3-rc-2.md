- data pack formatはRelease Candidate 1と同じ121.0
- component、predicate、registryの追加・改名は公式記事に記載なし
- Release Candidate 1の防御無効化と`match_block`の修正を継承。詳細は[component／predicate reference](../reference/components-and-predicates.md#263-release-candidate-1の挙動修正)を参照
