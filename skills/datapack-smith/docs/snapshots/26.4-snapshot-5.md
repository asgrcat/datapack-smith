# Java Edition 26.4 Snapshot 5

Snapshot 4を継承する開発バージョンです。launcher IDは`26.4-snapshot-5`、data pack formatは125.0です。Packed Ice Bricks系、Ice BallでFrostbiteを倒すadvancement、density functionの`upscale`、効果耐性tagの再編、item componentの音省略を収録します。

## metadata

```json
{
  "pack": {
    "description": "26.4-snapshot-5 data pack",
    "min_format": [125, 0],
    "max_format": [125, 0]
  }
}
```

## コマンド

- 生成したコマンド木はSnapshot 4と一致。block／item ID `minecraft:packed_ice_bricks`、`minecraft:packed_ice_brick_slab`、`minecraft:packed_ice_brick_stairs`、`minecraft:packed_ice_brick_wall`、`minecraft:chiseled_packed_ice`を追加
- sound event `minecraft:block.ice.ambient`を追加（Snapshot 4のregistryには存在しない）
- 効果耐性tagの変更は`effect`等の結果へ影響する。コマンド構文とmobの耐性を分けて検証する

## JSON/NBT/registry

- `minecraft:consumable.sound`、`minecraft:equippable.equip_sound`／`shearing_sound`は省略時に従来の既定音を補わなくなる。[item componentの移行](../json-parameters/items.md#264-snapshot-5の音field)
- density function `minecraft:interpolated`を`minecraft:upscale`へ改名。`input`と軸別の`x`／`y`／`z`設定を使う。各軸は`mode`と1〜64のinteger `cell_size`を持つ。[書式・modeと移行例](../reference/worldgen.md#264-snapshot-5の開発差分)
- feature `ore`／`scattered_ore`で、空気露出により置換を棄却したblockは次のreplacement ruleへ進まない。target ruleの順序と棄却率に依存する生成を再検証する
- biome tag `spawns_strays_without_powder_snow`を`spawns_cold_variants_underground`へ改名。vanillaの改名先は`ice_caves`を含む。公式記事の`spawns_ice_variants_underground`追加は生成dataと`BiomeTags`定数では確認できず、利用可能と断定しない
- entity type tag `ignores_poison_and_regen`を`immune_to_poison`／`immune_to_regeneration`へ分割。`freeze_immune_entity_types`を`immune_to_freezing`へ改名し、`immune_to_wither`／`immune_to_weakness`を追加。すべて`minecraft:`接頭辞を持ち、配置は`data/<namespace>/tags/entity_type/`
- Packed Ice Bricksとslab／stairs／wall、Chiseled Packed Iceを追加。2×2 Packed Iceによるcraftとstonecuttingに対応し、Packed Ice Bricks／Chiseled Packed IceはFast Sliding Sulfur Cube archetypeへ属する
- Ice BallでFrostbiteを倒すAdventure advancement「What Goes Around Comes Around」を追加。resource IDは`minecraft:adventure/what_goes_around_comes_around`。既存`minecraft:player_killed_entity` triggerでFrostbite、Ice Ballのdirect entity、projectile damage tagを判定する
- mobのprojectileによるDecorated Pot／Chorus Flower／speleothem破壊はAdventure worldでも有効で、`mob_griefing: false`時は抑止される
- 複数の効果耐性tagが同時に適用される判定（MC-270793）、undeadのPoison／Regeneration耐性（MC-312621）、ice cavesのportal／stronghold配置、playlistのchest更新・負の位置によるcrash等を修正

## 互換性

125.0固定metadataへ更新します。旧`interpolated`と共有`cell_size_xz`／`cell_size_y`を軸別設定へ変換し、削除tagの参照と独自tag定義を改名・分割します。省略時にも従来の音が必要なitemでは旧既定sound eventを明示します。Snapshot 4のfluid state・任意音field・crevasseの変更も継承します。

resource pack format 100.2、texture、DXGI設定、login protocolの変更はデータパックのJSON仕様と区別します。

## JSONパラメータ差分

- **item**: `consumable.sound`と`equippable.equip_sound`／`shearing_sound`の旧既定音を廃止。Packed Ice Bricks系を追加
- **dimension/worldgen**: `interpolated`を`upscale`へ改名し、軸別mode／cell sizeへ移行。ore／scattered_oreのrule選択とbiome tagを変更
- **enchantment**: Snapshot 4の`explode`演出field省略とfluid条件を継承。今回固有のschema変更は公式記事に記載なし
- **variant**: 地下のcold／ice variant spawn用biome tagを変更。sound variantの任意音fieldはSnapshot 4を継承
- **predicate**: entity type tagの耐性分割・改名を反映。worldgen `matching_fluids.state`はSnapshot 4を継承
- **advancement**: FrostbiteをIce Ballで倒すvanilla advancementを追加。既存`player_killed_entity` triggerを使う
- **loot_table**: Packed Ice Bricks系blockのdropを追加。既存schemaを継承
- **recipe**: Packed Ice Bricks系のcraft／stonecuttingを追加。既存schemaを継承
- **item_modifier**: Snapshot 4を継承。item componentを設定する場合は音fieldの省略結果を確認

## AI 生成規則

- launcher IDを`26.4-snapshot-5`、formatを125.0へ固定し、未収録の正式`26.4`へ丸めない
- project設定へ`experimental_features: true`を要求する
- 正式26.3のprovider型・参照形式とSnapshot 1〜4の変更を継承する。`default_block`、`minecraft:item_snowball`、`minecraft:large_dripstone`を生成しない
- fluid `flowing_water`／`flowing_lava`と旧`falling`を使わず、水源を`source`で明示する。block stateとfluid stateの`level`を区別する
- `minecraft:intentionally_empty`を使わず、対象codecで任意の音fieldを省略する。消費・装備・剪毛の旧既定音を維持する場合はsound eventを明示する。block sound setの旧`minecraft:amethyst`参照は`minecraft:amethyst_block`へ移行する
- density functionは`minecraft:upscale`の`input`と`x`／`y`／`z`を生成し、各軸に有効な`mode`と1〜64のinteger `cell_size`を指定する。旧`cell_size_xz`／`cell_size_y`を出力しない
- 旧耐性tagと`spawns_strays_without_powder_snow`を出力せず、改名・分割先を選ぶ
- crevasseの必須field・値域、`matching_fluids.state`の型を守る。worldgen、効果耐性、音、projectile、playlistの動作を対象JARで検証する

## 検証

Mojang公式記事・manifestを照合し、server JARのSHA-1 `ed041232700614aeaaf72a6ea88b7f58ca3f8e4a`を検証しました。JAR内`version.json`でformat 125.0、Java 25、`stable: false`を確認しています。

report／vanilla data生成は成功。Snapshot 4比で45ファイル追加、3ファイル削除、140ファイル変更（data generatorの`.cache`を除外し、ハーネス来歴metadataを含む）、コマンド木は一致です。registryのID差分、5種の氷block、advancement、craft／stonecutting、耐性tag、density functionの生成JSONとitem default componentを照合しました。`UpscaleFunction`と軸別codecの必須field・1〜64の値域、`Consumable`／`Equippable`の3つの音fieldの省略をJARのcodecで確認しています。

公式記事の`spawns_ice_variants_underground`は生成dataと`BiomeTags`定数に存在せず、`spawns_cold_variants_underground`を採用します。vanilla `ice_crevasse`の配置はcount 8→16、environment scanの`max_steps` 32→8へ変更されています。

server reload／ゲーム内動作検証は未実施です。Minecraft WikiはHTTP 403で取得できず、cross-checkは未実施です。
