# Java Edition 26.4 Snapshot 7

Snapshot 6を継承する開発バージョンです。launcher IDは`26.4-snapshot-7`、data pack formatは126.0です。Calcite系建材、新レコードFlurry、装飾block、`effect`の効果tag対応、時間引数の上限検査、equipment predicateのsaddle対応を収録します。

```json
  }

```

## コマンド

- `effect give`／`effect clear`の効果引数が`minecraft:resource`から`minecraft:resource_or_tag`へ変わり、`minecraft:mob_effect`のIDまたはtagを受け付ける。entity tagとは異なる。[tag定義と実行例](../reference/command-arguments-and-selectors.md#264-snapshot-7の効果tagと時間引数)
- 時間引数はtick換算・丸め後の値が2,147,483,647を超える場合にerrorとする。JARの`TimeArgument`はdouble入力を単位倍率で換算し、`Math.round`したlong値を範囲検査してからinteger化する。`effect give`の秒数は別のinteger引数で、この時間parserと混同しない
- コマンド木の差分は上記effect引数2か所。時間引数の上限検査はparser実装の変更で、report上のbranch追加ではない

## JSON/NBT/registry

- Calciteに`calcite_pillar`／`calcite_slab`／`calcite_stairs`／`calcite_wall`を追加。`polished_calcite`とslab／stairs／wall、`polished_calcite_bricks`とbrick slab／stairs／wallも追加。すべて`minecraft:`接頭辞を持つblock／item ID
- Polished Calciteは2×2 Calcite、Polished Calcite Bricksは2×2 Polished Calciteでcraft。Calcite系は対応するstonecutting recipeも追加。生成dataに追加されたrecipeは34件（craftとstonecuttingを含む）
- 公式記事が名称を伏せた装飾blockはJARで`minecraft:chiseled_soulshale`と確認。Ancient Cityのchest lootへweight 3で追加。対応recipeは生成dataに存在せず、craft可能と推測しない
- item tag `sulfur_cube_archetype/slow_bouncy`へCalcite Pillar、Polished Calcite、Polished Calcite Bricks、Chiseled Soulshaleを追加。slab／stairs／wallがすべて同じtagへ属するとは判断しない
- item `minecraft:music_disc_flurry`、jukebox song `minecraft:flurry`、sound event `minecraft:music_disc.flurry`を追加。songは154秒、comparator出力7。Iglooの`chests/igloo_chest`へ30%の独立poolで追加。itemの`minecraft:jukebox_playable`はsong IDを参照する
- entity type tag `minecraft:swimming`／`minecraft:flying`を削除。Snapshot 6で追加したfluid tag `minecraft:swimmable`は残る
- block sound set `minecraft:twisting_vines`を削除し、`minecraft:chiseled_soulshale`を追加。sound event `minecraft:entity.parrot.imitate.frostbite`とChiseled Soulshaleの5種の音を追加
- entity predicate `minecraft:equipment`内へ任意`saddle` item predicateを追加（MC-311029）。既存の装備slotやitem stack JSONとは区別する。[書式と例](../json-parameters/predicates.md#264-snapshot-7のequipment-saddle)
- 火がFreezingを革防具と同様に打ち消す。Zombie／Skeletonは革防具を1部位でも着用しているとFrostbite／Strayへ変換しない
- Deep Frozen Ocean、Frozen Ocean、Frozen Peaks、Frozen River、Jagged Peaks、Snowy SlopesへStray spawnを追加
- 高さ0〜3のtuff blob中の鉱石がdeepslate鉱石にならない不具合を修正。生成feature 30件のheight ruleを変更。Abandoned Campの欠落structure／tree、mobの攻撃範囲、落下尖頭blockのdamage、waxed copper golem、world border外のitem frame配置等も修正
- debug worldは通常の設置・破壊・コマンド変更を許可し、block見本を自動更新しなくなる。entity見本と対応するbabyを配置し、load時tick freeze、難易度Normalとする。`advance_time`／`advance_weather`／`spawn_wandering_traders`／`tnt_explodes`はfalse。通常world向けpackの仕様とは分けて扱う

## 互換性

単一対象のmetadataは126.0へ固定します。125.1と同じ構文・registry集合とは扱いません。効果tag引数とequipmentの`saddle`をSnapshot 6以前へ出力せず、削除されたentity type tagやblock sound setへの参照を更新します。`swimmable`のfluid tagを誤って削除しません。

Snapshot 6のdensity function・corner constraint・archetype location effect、Snapshot 5の`upscale`・効果耐性tag・任意item音field、Snapshot 4のfluid stateとcrevasseを継承します。resource pack format 102.0、texture、Graphics API、メニューとkeyboard navigation／narrationの変更はデータパックのJSON schemaと区別します。

## JSONパラメータ差分

- **item**: Calcite系12種、Chiseled Soulshale、Flurry discを追加。discの`jukebox_playable`は`minecraft:flurry`を参照
- **dimension/worldgen**: 6 biomeのStray spawnと鉱石height ruleを更新。Snapshot 6のdensity function／corner constraintを継承
- **enchantment**: Snapshot 6を継承。今回固有のschema変更は公式記事に記載なし
- **variant**: Slow Bouncy用item tagへ建材を追加。archetypeのlocation effectはSnapshot 6を継承
- **predicate**: `minecraft:equipment.saddle`を追加。entity type tag `swimming`／`flying`を削除。fluid `swimmable`は保持
- **advancement**: Calcite系craft／stonecuttingのrecipe解放advancementを追加。既存schemaを継承
- **loot_table**: 新blockのdrop、Ancient CityのChiseled Soulshale、IglooのFlurry discを追加
- **recipe**: Calcite系craft／stonecuttingを追加。Chiseled Soulshaleのrecipeを推測で生成しない
- **item_modifier**: Snapshot 6を継承。今回固有のschema変更は公式記事に記載なし

## AI 生成規則

- launcher IDを`26.4-snapshot-7`、formatを126.0へ固定し、未収録の正式`26.4`へ丸めない
- project設定へ`experimental_features: true`を要求する。正式26.3とSnapshot 1〜6の累積仕様を対象JARで確認する
- 効果tagは`data/<namespace>/tags/mob_effect/`へ定義し、`effect give`／`effect clear`の効果引数へ`#namespace:id`を渡す。entityのscoreboard tagやentity type tagへ置換しない
- 時間引数は単位換算・丸め後のtick値を2,147,483,647以下にする。commandごとの下限も守る。JSONのdurationや`effect give`の秒数へ同じparserの制約を推測で適用しない
- 削除された`minecraft:swimming`／`minecraft:flying` entity type tagと`minecraft:twisting_vines` block sound setを出力しない。fluid tag `minecraft:swimmable`と区別する
- `saddle`はentity predicateの`minecraft:equipment`内へitem predicateとして置く。26.2以降のcomponent-map形式と26.3以降のcondition形式を維持する
- 旧`interpolated`・共有cell size・旧耐性tag・`minecraft:intentionally_empty`・旧fluid ID／`falling`を使わない。`upscale`は軸別設定、水源は`source`で指定し、必要な音は明示する
- `gradient`のanchorはY軸だけ、`domain_warp`のoffsetは全軸定数0にしない。`corner_constraint`は1〜10件と各値域を守り、archetypeのlocation effectのlevelは1として解釈する
- 新block・disc・song・sound eventを正しいregistryで参照し、lootのweightと独立確率を混同しない。worldgen・効果・変換・音・debug worldのゲーム内動作は資料照合と別に検証する

## 検証

Mojang公式記事・manifestを照合し、server JARのSHA-1 `0870c02432ef2391ba7c586c3e113e98406aea20`を検証しました。JAR内`version.json`でformat 126.0、Java 25、`stable: false`を確認しています。

report／vanilla data生成は成功。Snapshot 6比で97ファイル追加、3ファイル削除、54ファイル変更（data generatorの`.cache`を除外し、ハーネス来歴metadataを含む）です。effectの引数2か所のparser変更、block／item／sound eventのregistry差分、recipe／loot、song、archetype tag、biomeと鉱石ruleを照合しました。

`EffectCommands`のtag展開、`EntityEquipmentPredicate`の任意`saddle` codec、`TimeArgument`のdouble入力・丸め・上限検査をJARで確認しました。serverを起動しないparser実行でも`2147483647t`と`107374182.35s`は受理、`2147483648t`と`107374182.4s`は拒否され、`1d`は24000 tickになることを確認しています。

server reload／ゲーム内動作検証は未実施です。Minecraft WikiはHTTP 403で取得できず、cross-checkは未実施です。
