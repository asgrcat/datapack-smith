# Java Edition 26.4 Snapshot 3

Snapshot 2を継承する開発バージョンです。launcher IDは`26.4-snapshot-3`、data pack formatは123.0です。氷の洞窟、新しいmob・効果・投射物と、block sound setのデータ駆動化を追加しています。

## metadata

```json
{
  "pack": {
    "description": "26.4-snapshot-3 data pack",
    "min_format": [123, 0],
    "max_format": [123, 0]
  }
}
```

## コマンド

- 生成したコマンド木はSnapshot 2と一致。既存構文で指定するregistry IDの追加・削除は別途反映する
- `minecraft:frostbite`、`minecraft:ice_ball`をentity ID、`minecraft:freezing`をmob effect IDとして使える
- particle `minecraft:item_snowball`を削除し、追加parameterなしの`minecraft:freezing`を追加。削除IDを使うfunctionを移行する

## JSON/NBT/registry

- biome `minecraft:ice_caves`を追加。寒冷なOverworld biomeの地下へ生成し、packed ice、calcite、icicle、ice crystal、鉱石patch、StrayとFrostbiteを含む
- block `minecraft:ice_crystal`、`minecraft:icicle`と、item `minecraft:ice_ball`、`minecraft:frostbite_spawn_egg`等を追加。Frostbiteは近接／遠距離攻撃を切り替え、近接でFreezingを与え、遠距離でIce Ballを投げる
- block reportでice crystalの`facing`（6方向）／`waterlogged`、icicleの`attached`／`thickness`（`tip_merge`、`tip`、`frustum`、`middle`、`base`）／`vertical_direction`（`up`、`down`）／`waterlogged`を確認。block stateはこの集合から選ぶ
- mob effect `minecraft:freezing`、potion `minecraft:freezing`／`minecraft:long_freezing`を追加。革装備は凍結を防ぐが効果自体の付与・継続とは別。Frostbiteは凍結に耐性を持ち、粉雪を歩ける
- `minecraft:block_sound_set` registryを追加。配置は`data/<namespace>/block_sound_set/<id>.json`、tagは`tags/block_sound_set/`。全fieldが省略可能な音量・pitch・5種類のSound Eventを定義する。詳細は[音と粒子reference](../reference/sounds-and-particles.md#264-snapshot-3のblock-sound-setとparticle)
- `speleothem_cluster`へ`placement_options`を追加。placement mode、base block stateの変換、water配置を設定する
- large featureのtypeはJARでは`minecraft:large_dripstone`から`minecraft:large_speleothem`へ改名。`base_block`はBlock State Provider。公式記事の改名方向と逆なので、生成物のtypeを採用する。resource ID `minecraft:large_dripstone`は引き続き存在する
- noise `minecraft:ice_cave_gradient`と21件の`ice_cave_ore_*` placed featureを追加。鉱石配置前に高さに応じたstone／deepslateのpatchを置く。詳細は[worldgen reference](../reference/worldgen.md#264-snapshot-3の開発差分)
- block tag `ice_cave_ore_replaceables`、`melts_icicle_above`、`large_icicle_replaceable`と、pathfinding用9 tagを追加
- item tag `frostbite_preferred_weapons`、`knocks_back_players_even_with_zero_damage`、`sheep_wool_dyes`を追加。羊の色は使用item stackの`minecraft:dye`から取得する
- biome tag `spawns_strays_without_powder_snow`、block sound set tag `sounds_wooden`を追加
- Ice Ballを試薬とするFreezing brewing recipeを追加。vanillaはawkward potionを入力に使う。長時間化、splash／lingering化も生成データで確認
- 雪をpacked iceへ置けるように変更し、snowballはplayerへknockbackを与える。ペットのportal移動座標（MC-303468）、キノコ島の小さいキノコ（MC-312198）、airを含むSuperflatのクラッシュ（MC-312213）を修正

## 互換性

123.0固定metadataへ更新したうえで、削除particle、feature type改名、`base_block`、追加registry・tagを確認します。Snapshot 2へ新しいIDやfieldを遡及しません。正式26.3の参照形式とSnapshot 1〜2のworldgen移行を継承します。

Friends／Other PlayersのUI変更、debug overlay、resource pack format 100.0とtexture資産は、データパックのJSON仕様と区別します。

## JSONパラメータ差分

- **item**: ice crystal、icicle、ice ball、spawn eggを追加。`sheep_wool_dyes`はitemの`minecraft:dye`を参照
- **dimension/worldgen**: ice caves、feature type改名、base block provider、placement options、noise、ore配置、tagを追加・更新
- **enchantment**: Snapshot 2を継承。固有のschema変更は公式記事に記載なし
- **variant**: Snapshot 2を継承。Frostbiteは新しいentity typeで、独自variant resourceとは解釈しない
- **predicate**: Snapshot 2の`below_heightmap`を継承。キノコ配置のfilter変更は対象vanilla dataを参照
- **advancement**: vanillaの探索・討伐対象へ新しいbiome／mobを反映。schemaは継承
- **loot_table**: Frostbiteのdrop tableを追加。schemaは継承
- **recipe**: Freezing potionのbrewing系を追加。ice crystal交換はrecipeとは別のvillager trade resource
- **item_modifier**: Snapshot 2を継承。固有のschema変更は公式記事に記載なし

## AI 生成規則

- launcher IDを`26.4-snapshot-3`、formatを123.0へ固定し、未収録の正式`26.4`へ丸めない
- project設定へ`experimental_features: true`を要求する
- 正式26.3のprovider型・参照形式とSnapshot 1〜2のworldgen移行を継承する。`default_block`を出力しない
- large featureの`type`には`minecraft:large_speleothem`を使い、resource IDとtype discriminatorを混同しない
- `placement_options`を指定する場合は3つの必須fieldを揃える。`base_block_transformer`はこのcodec固有のenumで、汎用block transformer registryのIDではない
- block sound setのvolume／pitch範囲を守り、sound eventの登録と音源資産の準備を分ける
- `minecraft:item_snowball`を使わず、任意item粒子への移行は対象JARの構文で確認する
- 新しいmob・effect・投射物の実動作、worldgen、reloadを対象JARで検証する

## 検証

Mojang公式記事・manifestを照合し、server JARのSHA-1 `2d89c95c030e635387448f332961074ce1adbb4b`を検証しました。`version.json`でformat 123.0、Java 25、`stable: false`を確認しています。

report／vanilla data生成は成功。Snapshot 2比で221ファイル追加、削除なし、97ファイル変更（ハーネス来歴metadataを含む）、コマンド木は一致です。block sound setの133要素とtag、registryのID増減、feature改名、recipeを確認しました。Sound Setとplacement optionsのcodecも照合しています。

server reload／ゲーム内動作検証と、取得できなかったMinecraft Wikiとの照合は未実施です。
