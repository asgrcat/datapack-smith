## コマンド

- Release Candidate 2を継承。公式記事に構文の追加・変更・削除は記載なし
- `/compute`と`data modify ... compute`のinteger／float branch、float `mod`の通常の剰余、float `pow`の`0^0`評価中止を継承

## JSON/NBT/registry

- data pack formatはRelease Candidate 2と同じ121.0
- component、predicate、registryの追加・改名は公式記事に記載なし
- Release Candidate 1の防御無効化と`match_block`の修正を継承。詳細は[component／predicate reference](../reference/components-and-predicates.md#263-release-candidate-1の挙動修正)を参照
- sprint中に別playerを攻撃しても攻撃側が減速しない不具合を修正（MC-311799）。PvPの移動・攻撃挙動を検証する際に考慮する
- VSyncの設定と実際の有効／無効が一致しない不具合（MC-311456、MC-311586）と、server編集時の「Server Resource Packs」設定が保存されない不具合（MC-311477）を修正。データパックのschema変更とは解釈しない
