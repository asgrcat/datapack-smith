# Java Edition 26.4 Snapshot 6

Snapshot 5を継承する開発バージョンです。launcher IDは`26.4-snapshot-6`、data pack formatは125.1です。Snow Bricks系、Cold Sulfur Cube、archetypeのlocation-based effect、density functionの拡張、structure pool elementのcorner constraintを収録します。

## metadata

```json
{
  "pack": {
    "description": "26.4-snapshot-6 data pack",
    "min_format": [125, 1],
    "max_format": [125, 1]
  }
}
```

## コマンド

- 生成したコマンド木はSnapshot 5と一致。block／item ID `minecraft:snow_bricks`、`minecraft:snow_brick_slab`、`minecraft:snow_brick_stairs`、`minecraft:snow_brick_wall`を追加
- sound event `minecraft:block.ice_crystal.ambient`を追加。下にPacked IceがあるIce Crystalの環境音に使う
- コマンド構文が同じでも、tag、変換NBT、worldgen、playlistやBrittle Iceの動作変更は個別に検証する

## JSON/NBT/registry

- `sulfur_cube_archetype`に任意list `location_based_effects`を追加。省略時は空list。各entryはenchantmentのlocation-based effectと同じ条件付き形式で、level依存値は常にlevel 1で評価する。[archetype書式](../reference/registry-formats.md#264-snapshot-6のarchetype拡張)
- `minecraft:cold` archetypeとitem tag `minecraft:sulfur_cube_archetype/cold`を追加。Blue IceをFast SlidingからColdへ移動。Coldは浮力を持ち、接地して移動を開始すると下の水をFrosted Iceの円盤へ変える。水の上に空気が必要。vanilla定義は乗り物上のcubeも除外する
- density function `minecraft:gradient`の`from_coordinate`／`to_coordinate`は、`axis: "y"`の場合だけVertical Anchorも受け付ける。X／Z軸はinteger座標を使う
- density function `minecraft:domain_warp`を追加。必須`input`と任意`offset_x`／`offset_y`／`offset_z`で入力の評価座標をずらす。省略offsetは0.0、結果は0方向へinteger化。少なくとも1軸を指定し、すべて定数0にはしない。[型・例・制約](../reference/worldgen.md#264-snapshot-6の開発差分)
- structure pool elementに任意`corner_constraint`を追加。density functionでbounding boxの角を検査する1〜10件のlist。`density_function`／`acceptable_density`／`required_corners`は必須、`padding`は0〜8（既定0）、`corners`は`all`／`top`／`bottom`（既定`all`）。必要角数は1〜8、`top`／`bottom`時は最大4。[配置例・範囲形式](../reference/structures-and-jigsaw.md#264-snapshot-6のcorner-constraint)
- fluid tag `minecraft:swimmable`、entity type tag `minecraft:swimming`／`minecraft:flying`を追加。配置はそれぞれ`tags/fluid/`、`tags/entity_type/`
- Snow Bricksは2×2 Snow Blockでcraftし、slab／stairs／wallも追加。stonecutting recipeはない。dropにはshovelを要求し、Snow BricksはFast Slidingへ属する。Packed Ice Brick系はdropにpickaxeを要求するよう変更
- `minecraft:nether/all_effects`と`minecraft:nether/all_potions`の判定へ`minecraft:freezing`を追加。advancement schema変更ではない
- `does_not_break_brittle_ice`へStrayを追加。Brittle Iceの`mob_griefing`／spawn protection／Shulker／lily pad／golem spawn判定、playlist切替時のsculk検知とdisc排出を修正
- ice cavesの鉱石重複とfeature順序cycle、tree下のdirt変換、villager trade、bucket由来Sulfur Cubeの分裂後despawnを修正。`dangerous_for_teleportation`へicicle／sulfur spikeを追加
- 不要な`DrownedConversionTime`／`InWaterTime`／`FrostbiteConversionTime`が変換対象外のmobへ残る不具合を修正。旧world更新で消費・装備音を失う不具合も修正。後者はSnapshot 5の任意音fieldへ旧既定値を戻すschema変更とは解釈しない

## 互換性

formatのminor更新です。単一対象のmetadataは125.1へ固定します。`max_format: 125`はmajor 125の全minorを許可するため厳密固定とは異なります。Snapshot 5以前へ新しいdensity function、anchor形式、corner constraint、archetype fieldやtagを出力しません。Blue IceをFast Slidingとして扱う独自tagや判定を見直します。

Snapshot 5の`upscale`・軸別設定・耐性tag再編・任意item音field、Snapshot 4のfluid state・音field・crevasseの変更を継承します。resource pack format 101.0、texture／model、既定JVM heap設定はデータパックのJSON schemaと区別します。

## JSONパラメータ差分

- **item**: Snow Bricks系4種とCold用item tagを追加。旧world更新時の消費・装備音を修正。音fieldの省略仕様はSnapshot 5を継承
- **dimension/worldgen**: `domain_warp`、Y軸`gradient`のVertical Anchor、pool elementの`corner_constraint`を追加。biome feature順序・重複を修正
- **enchantment**: location-based effectの形式をarchetypeでも使用。archetype内のlevel依存値はlevel 1固定
- **variant**: `sulfur_cube_archetype.location_based_effects`と`minecraft:cold`を追加。Blue Iceの対応archetypeを変更
- **predicate**: fluid `swimmable`とentity type `swimming`／`flying`のtagを追加。location effectの条件は対象consumerのcontextで検証
- **advancement**: `nether/all_effects`／`nether/all_potions`へFreezingを追加。既存schemaを継承
- **loot_table**: Snow Bricks系blockのdropを追加。Snow Bricks系はshovel、Packed Ice Brick系はpickaxeを要求
- **recipe**: Snow Bricks系のcraftを追加。Snow Brick系のstonecuttingは生成しない
- **item_modifier**: Snapshot 5を継承。今回固有のschema変更は公式記事に記載なし

## AI 生成規則

- launcher IDを`26.4-snapshot-6`、formatを125.1へ固定し、未収録の正式`26.4`へ丸めない
- project設定へ`experimental_features: true`を要求する。正式26.3とSnapshot 1〜5の累積仕様を対象JARで確認する
- `default_block`、`minecraft:item_snowball`、`minecraft:large_dripstone`、旧`interpolated`と共有cell size、旧耐性tagを生成しない。`upscale`は軸別modeと1〜64のinteger `cell_size`を指定する
- fluid `flowing_water`／`flowing_lava`と旧`falling`を使わず、水源を`source`で明示する。block stateとfluid stateの`level`を区別する
- `minecraft:intentionally_empty`を使わず任意音fieldを省略する。従来の音が必要ならsound eventを明示する。旧worldの音移行修正からcodec既定値の復活を推測しない
- `gradient`のVertical AnchorはY軸だけに使う。`domain_warp`は最低1つの有効なoffsetを指定し、全軸の定数0と急激で大きな座標変化を避ける
- `corner_constraint`はpool element内に置き、1〜10件と各fieldの値域・必須性を守る。`top`／`bottom`の必要角数を4以下にする
- archetypeの`location_based_effects`は条件付きlocation effectのlistとし、level依存値をlevel 1で解釈する。Cold用item tagとFast Sliding用tagを区別する
- crevasseや`matching_fluids.state`の型・値域を維持し、worldgen、音、氷、playlist、効果とNBT移行のゲーム内動作は資料照合と別に検証する
