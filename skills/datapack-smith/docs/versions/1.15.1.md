# Java Edition 1.15.1

1.15 のデータパック、command、JSON 仕様を変更しない performance/network hotfix です。[^source-c8aa3f125f][^source-89018b94cc]

## JSONパラメータ差分

- item: `inherits: 1.15`。item、recipe、loot、predicate parameterにこのバージョン固有の変更はない
- dimension/worldgen: 1.15を継承し、custom registryは未対応
- enchantment: 1.15の固定registryとitem NBT形式を継承
- variant: 1.15を継承し、data-driven variant registryはない
- predicate: 1.15の独立predicate schemaを継承し、このバージョン固有の追加・変更・削除はない
- advancement: 1.15のadvancement schemaを継承し、このバージョン固有の追加・変更・削除はない
- loot_table: 1.15のloot table schemaを継承し、このバージョン固有の追加・変更・削除はない
- recipe: 1.15のrecipe schemaを継承し、このバージョン固有の追加・変更・削除はない
- item_modifier: 1.15を継承し、独立resourceは未対応。このバージョン固有の追加・変更・削除はない

## AI 生成規則

1.15の仕様を完全継承し、1.15.1固有のデータパック機能を生成しません。
