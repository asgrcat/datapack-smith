# Java Edition 1.20.6

1.20.5のitem component/command/JSON仕様を継承する hotfix です。Trader Llama inventory のupgrade問題等を修正します。[^source-13919dec7a][^source-cea68ebe0b]

## JSONパラメータ差分

- **item**: 1.20.5 の item component、predicate、recipe／loot 形式を継承する hotfix で、このバージョン固有の追加・変更・削除はない。
- **dimension/worldgen**: 1.20.5 の number provider と dimension/worldgen 定義を継承する hotfix で、このバージョン固有の差分はない。
- **enchantment**: 固定レジストリと item component predicate を含め 1.20.5 を継承し、このバージョン固有の差分はない。
- **variant**: `wolf_variant` レジストリを含め 1.20.5 を継承し、このバージョン固有の差分はない。
- **predicate**: 1.20.5 のcomponent対応predicateを直接継承するhotfixで、このカテゴリ固有の追加・変更・削除はない。
- **advancement**: 1.20.5 のitem stack icon、trigger、predicate形式を直接継承するhotfixで、このカテゴリ固有の追加・変更・削除はない。
- **loot_table**: 1.20.5 のloot table、entry、condition、component対応functionを直接継承するhotfixで、このカテゴリ固有の追加・変更・削除はない。
- **recipe**: 1.20.5 のcomponent対応result形式を直接継承するhotfixで、このカテゴリ固有の追加・変更・削除はない。
- **item_modifier**: 1.20.5 のcomponent対応item modifierを直接継承するhotfixで、このカテゴリ固有の追加・変更・削除はない。

## AI 生成規則

1.20.5 component構文と複数形folderを使います。1.21の単数形folderへ移しません。
