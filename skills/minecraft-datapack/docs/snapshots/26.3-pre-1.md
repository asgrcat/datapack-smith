# Java Edition 26.3 Pre-Release 1

launcher IDは`26.3-pre-1`、data pack formatは119.0です。Snapshot 10のcontext依存number providerを整数用とfloat用へ分割し、コマンド、component、loot、predicate、recipe、worldgen、villager tradeの参照型を更新します。

## metadata

```json
{
  "pack": {
    "description": "26.3-pre-1 data pack",
    "min_format": [119, 0],
    "max_format": [119, 0]
  }
}
```

## コマンド

- `/compute`をnumber providerの分割へ合わせて変更
  - `/compute <target> integer <int_provider>`
  - `/compute <target> float <float_provider> [<scale>]`
  - provider評価が0除算等で失敗した場合はコマンドも失敗する
- `/data modify ... compute`をnumber providerの分割へ合わせて変更
  - `compute <target> integer <int_provider>`
  - `compute <target> float <float_provider>`
  - `/compute`と異なりfloat branchに`scale`はない

## JSON/NBT/registry

- `minecraft:number_provider`／`minecraft:number_provider_type`を削除し、context依存計算を次の4 registryへ分割
  - 整数値: `minecraft:context_int_provider`／`minecraft:context_int_provider_type`
  - float値: `minecraft:context_float_provider`／`minecraft:context_float_provider_type`
  - worldgen等のcontext非依存`minecraft:int_provider_type`／`minecraft:float_provider_type`とは別registry
- 旧provider typeをinteger variantとfloat variantへ分割し、演算名と入力fieldを整理
  - `sum` → `add`、`product` → `mul`、`minimum` → `min`、`maximum` → `max`、`average` → `avg`
  - 集約演算の入力fieldは`inputs`。inline値、単一ID、ID／inline値のlist、provider tagを受け、1要素以上が必須
  - `constant`、`uniform`、`storage`、`add`、`mul`、`min`、`max`、`avg`、`weighted_list`、`conditional`、`number_dispatcher`、`environment_attribute`はinteger／floatの両variantを持つ
  - 全51 typeのfield、四則演算、丸め、三角関数、分岐、失敗条件は [`../reference/number-providers.md`](../reference/number-providers.md) を参照
  - Mojangの記事は`conditional.conditions`と記載するが、Pre-Release 1の公式JARが生成するvanilla JSONに合わせて`conditional.condition`を使う
- integer providerは32-bit整数で計算
  - `abs`、`sub`、`negate`、`pow`、`div`、`floor_div`、`mod`、`floor_mod`、`from_float`を追加
  - `binomial`と`score`はinteger variantだけで使用可能
  - `div`／`mod`は0方向、`floor_div`／`floor_mod`は負の無限大方向の除算規則を使う
  - overflow、0除算、不正な変換は計算を失敗させる。`from_float`は0方向へ切り捨てる
- float providerはsingle-precision floatで計算
  - `abs`、`sub`、`negate`、`pow`、`div`、`mod`、`ceil`、`floor`、`round`、`truncate`、`sin`、`cos`、`sqrt`、`length`、`from_int`を追加
  - `enchantment_level`はfloat variantだけで使用可能
  - `round`は最近傍へ丸め、tieは正の無限大方向。`sin`／`cos`の入力単位はradian
  - NaNまたはInfinityを生成する計算結果の挙動は未定義
- vanilla providerを移行
  - compostable、cooking time、brewing usesは`minecraft:context_int_provider`へ移動
  - cooking／brewingのspeed providerは`minecraft:context_float_provider`へ移動
  - `cooking/normal_burn_time_multiplier`／`cooking/fast_burn_time_multiplier`を削除し、対応する`*_burn_time_reduction_factor`へ置換
- item componentを変更
  - `minecraft:cooking_fuel.burn_time`と`minecraft:brewing_fuel.uses`、`minecraft:compostable.layers`はinteger provider
  - `minecraft:cooking_fuel.speed_multiplier`と`minecraft:brewing_fuel.speed_multiplier`はfloat provider
  - fuelにremainder itemがある場合、fuelが残ればremainderをdropし、使い切ればfuel slotへ残す
- loot tableの`rolls`をinteger provider、`bonus_rolls`をfloat providerへ変更
- loot functionのprovider型を変更
  - float: `set_attributes.modifiers[].amount`、`enchanted_count_increase.count`、`set_custom_model_data.floats[]`、`set_damage.damage`
  - integer: `enchant_with_levels.levels`、`set_custom_model_data.colors[]`、`set_enchantments.enchantments.*`、`set_count.count`、`limit_count.limit.min|max`、`set_ominous_bottle_amplifier.amplifier`、`set_random_dyes.number_of_dyes`、`set_stew_effect.effects[].duration`
  - `limit_count.limit`は単一数値を受けなくなり、range objectが必要
- predicateを変更
  - `random_chance.chance`はfloat provider
  - `minecraft:value_check`を削除し、`minecraft:int_value_check`と`minecraft:float_value_check`へ分割。各conditionは`value`と、単一値または`min`／`max` objectの`test`を受ける
  - `time_check`と`entity_scores`の値／範囲へinteger providerを使用可能
- cooking recipeの`cookingtime`を必須化
  - 旧既定値へ依存したrecipeは`200`を明示する
  - smoker／blast furnaceのcustom recipeは以前の値の2倍へ移行し、実時間を維持する
- block state providerを`worldgen/block_state_provider`の独立resourceとして定義し、namespaced IDで参照可能
  - inline block state objectは`minecraft:simple`の省略形として使用可能だが、block ID文字列だけの省略形は不可
  - type名から`_provider` suffixを削除: `dual_noise`、`noise`、`noise_threshold`、`randomized_int`、`rule_based`、`simple`、`weighted`、`random_block`、`rotated`
  - `minecraft:rule_based`はruleが結果を返さなければ後続ruleを評価し、全ruleとfallbackが結果を返さなければprovider全体も結果なしになる
- villager tradeの`max_uses`／`xp`、`wants.count`／`additional_wants.count`をinline integer provider、`reputation_discount`をinline float providerへ変更
- item tag `#minecraft:furnace_fuel_bottom_takeable`を追加

## 互換性

118.0の`minecraft:number_provider` IDとtag、旧type名、`operands` fieldは119.0で無効です。各利用箇所が要求する整数／float registryへresourceとtagを分離し、`add`／`mul`／`min`／`max`／`avg`の入力を`inputs`へ移します。暗黙の整数化に依存せず、必要な境界だけ`from_float`または`from_int`で明示します。

`/compute`と`data modify ... compute`はbranch順が変わります。Snapshot 10のprovider直後に`integer`を書く構文を機械置換せず、`integer|float`をtarget直後へ置き、floatの`scale`は`/compute`だけで使用します。

loot、component、predicate、tradeの各fieldは要求するprovider registryが異なります。同じ定数でも整数fieldには整数値、float fieldにはfloat値を出力し、`limit_count.limit`、`value_check`、cooking recipe、block state provider typeの破壊的変更をまとめて移行します。

## JSONパラメータ差分

- **item**: cooking／brewing fuelとcompostableをinteger／float providerへ分離し、remainder itemのslot／drop挙動を変更。`#minecraft:furnace_fuel_bottom_takeable`を追加
- **dimension/worldgen**: block state providerを独立registry化し、inline省略形、provider type rename、`rule_based`の結果なし処理を変更
- **enchantment**: context依存number providerを整数／float registryへ分割し、`enchantment_level`をfloat専用化
- **variant**: 26.3-snapshot-10を継承。固有のvariant registry追加・変更・削除なし
- **predicate**: `random_chance`、`time_check`、`entity_scores`を新provider型へ移行し、`value_check`を`int_value_check`／`float_value_check`へ分割
- **advancement**: 26.3-snapshot-10のroot背景制約を継承。condition内のnumber providerは119.0の整数／float分割を適用
- **loot_table**: `rolls`をinteger provider、`bonus_rolls`をfloat providerへ変更
- **recipe**: cooking recipeの`cookingtime`を必須化し、smoking／blastingの値を新しい速度規則へ移行
- **item_modifier**: 各loot functionの数値fieldをinteger／float providerへ分離し、`limit_count.limit`の単一数値形を削除

## AI 生成規則

- launcher IDを`26.3-pre-1`、data pack formatを119.0へ固定し、`26.3-snapshot-10`や`26.3-pre1`へ丸めない
- context依存providerへ旧`minecraft:number_provider`、`sum`／`product`／`minimum`／`maximum`／`average`、`operands`を出力しない
- providerの利用fieldごとにinteger／floatを選び、両者を暗黙変換せず`from_float`／`from_int`を明示する
- `/compute`と`data modify ... compute`ではtarget直後に`integer|float`を置き、`scale`を`data modify`へ出力しない
- `minecraft:value_check`、単一数値の`limit_count.limit`、`cookingtime`なしのcooking recipe、旧block state provider typeを出力しない
- integer演算はoverflow、0除算、負数の除算規則を、float演算はNaN／Infinity、丸め、single precisionを含めて検証する
- Pre-Release 1の公式JARでcommand report、datapack registry、vanilla data、reload、provider評価、recipe時間、worldgenを再検証する
